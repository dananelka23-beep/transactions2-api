#1# What problem does the model file solve?
The model file works with MongoDB. It saves transactions and gets transaction data from the database.

#2# What problem does the controller file solve?
The controller file handles the requests from the routes and sends responses back to the user.

#3# What problem does the route file solve?
The route file connects the API URLs to the correct controller functions.

#4# How is this project different from the previous Transactions API?
This project is more organized because everything is separated into models, controllers, and routes. It also uses MongoDB Atlas and Heroku.

#5# Why should financial transactions avoid destructive edits?
Financial transactions should not be deleted because it is important to keep the history of all money records and changes.

#6# What is the purpose of the seed.js file?
The seed.js file adds sample transactions into the database for testing the API.

#7# What is the difference between the local MongoDB URI and the Atlas MongoDB URI?
The local MongoDB URI connects to MongoDB running in Docker on the local computer. The Atlas MongoDB URI connects to MongoDB Atlas online.

#8# What was the most difficult part of this assignment?
The most difficult part for me was setting up Atlas, Heroku, and fixing the GitHub permission problems.
